# Product Claims Language

ข้อความใน MVP และ pitch ใช้ภาษาไทยเท่านั้น ยกเว้น code identifiers, methodology codes และข้อความอ้างอิงทางการที่ต้องคงต้นฉบับ

## ต้องใช้

- “ค่าประมาณ CO2e ที่อ้างอิงปัจจัย/ระเบียบวิธีของ TGO แบบมีเวอร์ชัน”
- “หลักฐานการนำวัสดุมาส่ง” สำหรับ recycling claim
- “ค่าการกักเก็บที่คาดการณ์ไว้หนึ่งปี” สำหรับ tree claim
- “กฎตรวจรถโดยสารเป็นฮิวริสติกของ MVP”
- “ข้อมูลเดโม” บนทุก synthetic record/surface

## ห้ามใช้

- “TGO-certified”, “ได้รับการรับรองโดย อบก.”, “carbon credit” หรือ “offset”
- “ป้องกันการโกงได้”, “พิสูจน์ว่าโดยสารจริง” หรือคำกล่าวอ้าง accuracy ที่ยังไม่มี validation
- “รีไซเคิลสำเร็จ” เมื่อมีเพียง QR, ภาพ และ reviewer-visible material
- “ต้นไม้จะอยู่รอด” หรือการสะสม projection มากกว่าหนึ่งปี
- ชื่อ/โลโก้ partner จริงหรือคำกล่าวอ้าง payment/settlement ที่ยังไม่มี

Factor catalog ต้องเก็บ Thai proxy/disclaimer copy ที่ผ่าน project owner/domain reviewer approval ก่อนสร้าง value
